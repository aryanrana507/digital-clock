# Digital Clock

A beautiful live digital clock — web development project.

- **Live time** — hours : minutes : seconds, blinking colon, glowing digits
- **Date + day** — e.g. Thursday • 26 November 2026
- **12 / 24-hour toggle** (button or press `T`)
- **5 colour themes** — cyan, orange, pink, green, violet (saved in your browser)
- **Seconds progress bar** — shows how far into the current minute you are
- **Fullscreen mode** (button or press `F`)
- Works offline — just open `index.html` in any browser. No install, no build step.

## Run it

Double-click `index.html`, or open it from the live link below.
